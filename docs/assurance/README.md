# 公開の前に成り立つべきこと

この SDK の本線 (日付版のコア) を push し、版ごとのタグを付け替える前に、成り立っていなければならない主張と、その根拠の台帳。

- `release.json` — 台帳。主張ごとに、支持する証拠と否定する証拠を書く。
- `release.md` — 台帳を判定した結果。`assurance check docs/assurance/release.json > docs/assurance/release.md` で作り直す (`foundation/nim-assurance`)。
- 判定は四値である: 成り立つ / 成り立たない / 証拠が食い違っている / 誰も確かめていない。必須の主張がすべて「成り立つ」になるまで、公開できない。

公式拡張 (`mcp-2026-07-28-ext`) と下書き (`mcp-draft`) の主張は、まだここに無い。

## 2026-11-19 の状態

28 の主張 (うち必須 22) のうち、成り立つのは 21、成り立たないのは 0、証拠が食い違っているのは 0、誰も確かめていないのは 7 (うち必須 2)。**公開できない。** 必須で残るのは、変異検査の測り直し (REV-01、REV-01b) だけである。

2026-10-14 から変わったもの:

- DEP-01 — nimble の下限を `nim >= 2.4.2` に上げた (2026-11-18、代表の決定)。2.4.2 は `base64.decode` の欠陥 nim-lang/Nim#25530 の修正 (v2.2.10 以降) を含む。上げた理由は TLS である。2.2.14 からの `asyncnet` はハンドシェイクで証明書の名前を確かめるので、名前の合わない証明書を拒否するときの文言が、版によって変わっていた。
- DEP-03 — Nim 2.4.2 を既知の欠陥の一覧と突き合わせ、該当は 0 件だった。一覧の 5 件のうち Nim のものは 1 件で、残りはこの SDK が使わない部品 (zippy、openzeppelin-contracts) のものである。
- SEC-03 — 2.4.2 では標準ライブラリも名前を確かめる。ただし SAN が合わなくても CN が合えば通すので、SDK の確かめ (RFC 6125 6.4.4) は残し、CN だけがホスト名と同じ証明書を SDK が拒否するテストを足した。
- OPS-01 — 2.4.2 の `asynchttpserver` は `readTimeout` を持つが `headerFields` を持たないので、SDK は写し (`src/transport/vendor/asynchttpserver.nim`) を使い続ける。写しは、時間内に読めた要求が `readTimeout` のタイマーをイベントループに残さない直しを含む (本家には nim-lang/Nim#26460 の 2 つ目のコミットとして出す)。
- VER-01b、VER-02、IOP-01b、CNF-01b — 2026-11-19 に、Nim 2.4.2 と本線の新しいコミットで測り直した ([release-check-2026-11-19.md](../quality/release-check-2026-11-19.md))。5 版の通し、版ごとの展開、相互接続 312 行、適合性テスト 212 シナリオで、失敗・不合格は 0 だった。取り直しの途中で、古い版を既定にしたビルドで落ちるテストが 5 本見つかったので直した (どれもテストの側の前提の誤りで、SDK 本体の失敗ではない)。**ソースかテストが変わったら、この 4 つは取り直す。**
- SPEC-01 — 「証拠が食い違っている」から「成り立つ」に変わった。外部仕様テストの無かった 6 つの ID は、外部仕様テストを足すか、代表の決定で外部仕様から外した (2026-10-17)。

誰も確かめていないもの: 変異検査の測り直し (REV-01、REV-01b。必須)、下流のパッケージのコンパイル (DOWN-01)、性質の証明 (PRF-01、PRF-02)。INP-02 と SEC-02 は、商用製品の公開に課すゲートで、この SDK の公開には課さない (利用者の決定、2026-10-18)。

## 証拠を足すとき

- 証拠は、主張を支持するか否定するかを書く。確かめた日と、確かめ方を `ref` に書く。
- ファイルを指せる証拠は `file` に書く。台帳を読み込むとき、そのファイルが無ければエラーになる。
- **確かめていないことを、支持する証拠として書かない。** 文書に「そうなっている」と書いてあることは、そうなっていることの証拠ではない。
- 食い違う証拠は、どちらも残す。
